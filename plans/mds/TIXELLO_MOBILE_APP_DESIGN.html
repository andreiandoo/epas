Tixello · Design mobil

Aplicația Tixello pentru staff: vinde, scanează, raportează — de pe orice telefon.

O singură aplicație multi-brand care servește orice tenant al platformei și orice organizator dintr-un marketplace. Modelată după app-ul de scanare existent (Tixello Scan / ambilet-app2), generalizată la întreaga platformă. Temă întunecată, mobile-first, adaptivă pe rol.

Adaptare pe rol & context

Aceeași aplicație, navigație și permisiuni diferite.

Owner / Admin
Toate taburile: panou, scanare, vânzare, rapoarte, echipă, porți, setări, payout.
Manager
Panou, scanare, vânzare, rapoarte. Fără gestiune echipă/finanțe.
Casier · pos_cashier
Vânzare + sesiune casă. Panou-tură. Fără scanare.
Scanner · check_in
3 taburi: panou-tură, scanare, mai mult. Fluxul cel mai rapid.
admin_mobile
Scanare + vânzare pe același dispozitiv mobil.
Venue-owner
Read-only + scanare pentru evenimentele din locația proprie (/venue-owner/scan).
Un cont, oricâte contexte
1Login (email + parolă)
→
2Rezolvă context: tenant / marketplace / venue
→
3Branding runtime (logo · culori)
→
4Rutare API + permisiuni pe rol

Un rewriter de API mapează căile după context: organizator → /marketplace-client/organizer/*, venue-owner → /marketplace-client/venue-owner/*, tenant → /tenant-client/* (rezolvat pe domeniu). Autentificare unică prin Sanctum; cheia de marketplace doar identifică brandul, nu se împachetează în binar.
